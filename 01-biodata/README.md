# Tugas 01 — Biodata Diri

## Tujuan
Melatih penggunaan variabel `let` dan `const`.

## Instruksi
1. Simpan data dirimu ke dalam variabel: nama, umur, asal sekolah, dan hobi.
2. Pikirkan baik-baik: data mana yang cocok pakai `const`, mana yang pakai `let`?
3. Tampilkan kalimat perkenalan yang rapi di console menggunakan variabel-variabel itu.

## Contoh Output
```
Halo! Nama saya Budi.
Saya berumur 17 tahun, dari SMK Negeri 1.
Hobi saya: futsal dan ngoding.
```

> Tulis di sini (3–5 kalimat, bahasamu sendiri):

> - Kenapa kamu memilih `const` untuk data tertentu dan `let` untuk data lainnya?
