# Tugas 03 — Tabel Perkalian

## Tujuan
Melatih perulangan dan memahami *kapan* perulangan dibutuhkan.

## Instruksi
1. Simpan satu angka di dalam variabel (contoh: 7).
2. Gunakan perulangan untuk mencetak tabel perkalian 1 sampai 10 dari angka itu.
3. Boleh pakai `for`, `while`, atau `do while` — bebas, tapi sebutkan di penjelasan kenapa kamu memilihnya.

## Contoh Output
```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...
7 x 10 = 70
```
