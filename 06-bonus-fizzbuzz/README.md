# Tugas Bonus — FizzBuzz

## Tujuan
Tantangan klasik wawancara kerja: gabungan perulangan + pengkondisian.

## Instruksi
Cetak angka 1 sampai 100 dengan aturan:
- Kelipatan 3 → cetak "Fizz"
- Kelipatan 5 → cetak "Buzz"
- Kelipatan 3 DAN 5 → cetak "FizzBuzz"
- Selain itu → cetak angkanya

## Contoh Output
```
1
2
Fizz
4
Buzz
Fizz
7
...
14
FizzBuzz
...
```

## Penjelasan
> Tulis di sini (3–5 kalimat, bahasamu sendiri):
> - Bagaimana caramu menyelesaikan tugas ini?
> - Kenapa kondisi "FizzBuzz" harus dicek paling awal? Apa yang terjadi kalau tidak?
