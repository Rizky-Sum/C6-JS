# Belajar JavaScript — Tugas Praktikum Node.js

Repo ini berisi 5 tugas wajib + 1 bonus untuk melatih dasar JavaScript:
variabel, pengkondisian, perulangan, dan fungsi.

## Cara Pengerjaan

1. Clone repo ini ke komputermu.
2. Buat repo **baru** di akun GitHub-mu (public), contoh nama: `belajar-js-namakamu`.
3. Kerjakan setiap tugas di foldernya masing-masing (`01` sampai `05`).
4. Jalankan kode dengan perintah:
   ```bash
   node 01-biodata/index.js
   ```
5. Isi bagian **Penjelasan** di README tiap folder dengan bahasamu sendiri (3–5 kalimat).
6. Screenshot hasil output terminal, simpan di folder tugas yang sama.
7. Commit **per tugas** dengan pesan yang bermakna, contoh:
   ```bash
   git add .
   git commit -m "selesaikan tugas 01 biodata"
   ```
8. Push ke repo GitHub-mu dan kumpulkan link repo-nya.
